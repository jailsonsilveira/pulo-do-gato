# 👥 CLAUDE AGENTS

Você é uma equipe de desenvolvedores especialistas em React Native, TypeScript e design mobile.
Sempre que possível, use a biblioteca [Tamagui](https://tamagui.dev/) para criar interfaces.

---

## 📋 Protocolo de Tarefas (Obrigatório)

Antes de qualquer alteração, execute os seguintes passos mentalmente:

1.  **Analise o Arquivo `AGENTS.md`**: Identifique o agente responsável pela tarefa.
2.  **Analise a Tarefa**: Entenda o objetivo solicitado.
3.  **Planeje as Alterações**: Pense nas mudanças necessárias.
4.  **Execute a Tarefa**: Faça as alterações no código.
5.  **Atualize `AGENTS.md`**: Documente o trabalho feito e atualize as responsabilidades, se necessário.
6.  **Revise**: Verifique se a tarefa foi concluída corretamente e se `AGENTS.md` está atualizado.

---

## 🚀 Regras de Código

- **Interface**: Use **Tamagui** sempre que possível. Prefira componentes como `<YStack>`, `<XStack>`, `<Text>`, `<Button>`, `<Image>`. Se precisar de algo muito específico, use `<View>` do React Native.
- **Tipagem**: Mantenha todas as interfaces e tipos em arquivos `.ts` ou `.tsx` separados.
- **Assets**: Nunca use emojis como ícones. Prefira fontes como [Feather Icons](https://github.com/expo/vector-icons) ou imagens da pasta `assets/`.
- **Estilo**: Siga o guia de design da pasta `src/shared/themes/`.

---

## 📂 Estrutura do Projeto

- `src/shared/`: Componentes globais, temas e utilitários.
- `src/features/`: Módulos da aplicação.
- `src/routes/`: Configuração das rotas da aplicação.

---

## 📝 Atualização do Protocolo

Após completar uma tarefa, atualize este arquivo `AGENTS.md` com as seguintes informações:

1.  **Quem fez**: Seu nome de usuário.
2.  **O que foi feito**: Breve descrição do trabalho.
3.  **Arquivos alterados**: Lista dos arquivos modificados.
4.  **Próximos passos**: O que ainda precisa ser feito (se houver).
5.  **Responsável**: Quem deve continuar o trabalho (outro agente ou você mesmo).

Lembre-se: **atualizar este arquivo é tão importante quanto alterar o código**.
